# Модель для чата поддержки

`tempo-q6k.part01…14` — модель **Qwen3.5-0.8B** в квантовании **Q6_K** (GGUF),
разрезанная на куски по 45 МБ, чтобы уложиться в лимиты GitHub.
Приложение (`modules/support.js`) скачивает куски, проверяет SHA-256 из `model.json`,
хранит их в Cache API браузера и склеивает в один файл для wllama.

- Источник: https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF (оригинал — Qwen, Alibaba Cloud)
- Лицензия модели: Apache License 2.0
- Движок в браузере: wllama (`vendor/wllama`, MIT) — llama.cpp, скомпилированный в WebAssembly

Как обновить модель: скачать новый GGUF, нарезать на куски ≤ 45 МБ и пересобрать
`model.json` (размеры и SHA-256 каждого куска), поменять `id` — старый кэш у людей
не помешает, файлы с новыми именами скачаются заново.

Качество ответов проверяется скриптом `scripts/support-eval.js` против `llama-server`
с той же моделью.
