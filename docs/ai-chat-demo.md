# Темп — чат поддержки на нейросети (демо, отложено)

**Статус:** убран из Tempo 23.10.2026. Был в приложении с коммита `8e19272` по `fcaff6a`.
**Почему отложили:** слишком тяжёлый для телефона и ломал сайт, а качество ответов маленькой модели не стоило этой цены.

## Что это было

Кнопка-облачко в верхней панели открывала полноэкранный чат с «Темпом» — собеседником для поддержки:
тревога, усталость, ссоры, радость, сон, учёба. Нейросеть работала **прямо в браузере**, без сервера:
переписка не покидала устройство.

| Часть | Как сделано |
|---|---|
| Движок | [wllama](https://github.com/ngxson/wllama) 3.6.1 — llama.cpp, скомпилированный в WebAssembly (`vendor/wllama`, 8,4 МБ wasm) |
| Модель | Qwen3.5-0.8B, квантование Q6_K, **639 МБ** (Apache 2.0) |
| Доставка | файл нарезан на 14 кусков по 45 МБ (лимит GitHub), `ai/model.json` хранит размеры и SHA-256 |
| Хранение | куски качались в Cache API, проверялись по SHA-256 и склеивались в один файл в OPFS |
| Запуск | ПК: контекст 2048, несколько потоков (нужна изоляция страницы COOP/COEP через service worker). iPhone: контекст 1024, один поток |
| Генерация | temperature 0.5, top_p 0.85, top_k 30, min_p 0.05, без штрафов за повторы (в русском они ломают окончания), до 150 токенов |

### «Мозг» вокруг модели (`modules/support-brain.js`)

0.8B-модель сама по себе путается, поэтому всё, что можно, делал код:

- **Распознавание состояния** по ключевым словам: тревога, грусть, усталость, злость, учёба, отношения и т.д. Под каждое состояние в системный промпт шла короткая подсказка и подставлялись 2 эталонных примера.
- **Первая фраза ответа писалась кодом** (префилл), модель её продолжала. Так ответ всегда начинался с того, что человека поняли.
- **Чистка ответа:** чужие алфавиты, списки, повторы, переход на «вы» (с автозаменой на «ты»), недописанные фразы. Плохой ответ генерировался заново, при второй неудаче брался готовый запасной.
- **Без модели:**
  - кризисные фразы → ответ с телефонами помощи;
  - шутки из готового списка;
  - техники кнопками: дыхание 4–6, заземление 5–4–3–2–1, правило 5 минут.
- **Статистика и советы считались кодом из данных Tempo:** неделя против прошлой (баллы, привычки, пары, тренировки, сон, настроение, вода, вес) и главный совет. Модель цифры не выдумывала.

## Что получилось

- На ПК всё работало. Модель скачивается один раз, потом загружается из OPFS примерно за 2 с, а ответ печатается за несколько секунд, даже офлайн.
- Разбор недели и советы — точные и полезные, потому что их считал код, а не модель.
- Кризисные сообщения обрабатывались надёжно.

## Почему не взлетело

1. **Память.** wllama копирует всю модель в память WebAssembly: 640 МБ плюс буферы. Safari на iPhone убивает такую вкладку («веб-страница перезагружена, так как использовала слишком много памяти»), а в режиме веб-приложения бывал белый экран.
2. **Вес.** 640 МБ скачивания ради одной функции. Плюс 2/3 лимита GitHub Pages (1 ГБ на сайт).
3. **Качество.** Модель 0.8B не умеет по-настоящему болтать: ответы «пластиковые», повторы, слабо держит контекст. Даже при всех подпорках выше.

## Если возвращаться

- **Облако вместо телефона.** Например, Cloudflare Workers AI (есть бесплатный лимит) через маленький прокси: живая беседа, ничего не нужно скачивать. Минус — переписка уходит на сервер, нужно явное согласие пользователя.
- **Гибрид.** Модель на устройстве только на ПК, на телефоне — облако или простой режим.
- **Подождать.** WebGPU в Safari и модели поменьше (≤ 350 МБ) при приличном качестве. Перед запуском проверить память на реальном iPhone.
- **Без нейросети.** Разбор недели, советы, техники и кризисный ответ работают без модели. Их можно выпустить отдельно, например карточкой «Итоги недели».

Задумки, которые не успели выйти:
- **Защита от вылетов:** если вкладка падала во время запуска модели, чат больше не запускал её сам.
- **Простой режим:** готовые ответы по теме, когда модели нет.

Они лежат в локальной копии рядом с проектом (`Tempo-ai-demo/`).

## Как восстановить код

Последняя версия на GitHub — коммит `fcaff6a`:

```bash
git checkout fcaff6a -- modules/support.js modules/support-brain.js scripts/support-eval.js vendor/wllama ai
```

Дальше вернуть подключение (всё есть в диффе `8e19272`):
- кнопку `#sup-btn` и два `<script>` в `index.html`;
- стили `.sup-*` в `style.css`;
- изменения в `sw.js`: файлы в `ASSETS`, изоляцию COOP/COEP, пропуск `/ai/`.

## Что сделано при удалении

- Удалены `modules/support*.js`, `scripts/support-eval.js`, `vendor/wllama`, `ai/`.
- `index.html` и `style.css` вернулись к версии до чата.
- `sw.js` больше не включает изоляцию страницы и при обновлении удаляет кэш модели.
- `app.js` один раз удаляет у пользователей склеенную модель из OPFS и освобождает ~640 МБ.
- Переписка (`DATA.support`) осталась в данных пользователя — пригодится, если чат вернётся.
- В истории git куски модели остались: они в коммитах `8e19272` и `fcaff6a`.
